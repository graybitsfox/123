# Intelligent NPCs - Minecraft Fabric Mod

Мод **Intelligent NPCs** для Minecraft 1.21 с интеграцией искусственного интеллекта, который добавляет в игру интеллектуальных NPC с расширенными возможностями.

## 🤖 Особенности

### Интеллект и Личность
- **LLM-интеграция** - NPC управляются через языковые модели (OpenAI GPT, Ollama)
- **Долговременная память** - NPC помнят взаимодействия с игроками и события
- **Эмоции и настроение** - динамические эмоциональные состояния
- **Уникальная личность** - каждый NPC имеет свои черты характера

### Возможности NPC

#### 🏗️ Строительство (BuilderAI)
- Постройка домов, башен, мостов, ферм
- Планирование и выбор материалов
- Обучение новым стилям строительства
- Командная работа при больших проектах

#### 💼 Торговля (TradeAI)
- Динамическое ценообразование
- Переговоры и торги с игроками
- Анализ рынка и спроса
- Торговля с другими NPC и жителями

#### 💬 Общение (ChatAI)
- Естественное общение с юмором и сарказмом
- Реакция на события в чате
- Эмоциональные ответы
- Поддержка черного юмора (опционально)

#### 🛡️ Выживание (SurvivalAI)
- Реакция на все виды опасностей Minecraft
- Автоматическое тушение огня
- Поиск укрытия от дождя и ночных мобов
- Избегание лавы, падений, взрывов

#### ⚔️ Боевая система (CombatAI)
- Адаптивные тактики боя
- Защита союзников
- Анализ угроз и выбор стратегии
- Работа в команде

#### 📚 Обучение (LearningAI)
- Наблюдение за действиями игроков
- Копирование и адаптация поведения
- Экспериментирование с новыми подходами
- Улучшение навыков со временем

#### 👥 Командная работа (TeamAI)
- Формирование команд NPC
- Распределение ролей и задач
- Координация сложных проектов
- Взаимопомощь и поддержка

## 🎮 Команды

### Основные команды
```
/npc create <имя> [роль]          - Создать NPC
/npc remove <имя>                 - Удалить NPC
/npc list                         - Список всех NPC
/npc info <имя>                   - Информация об NPC
/npc teleport <имя> [x] [y] [z]   - Телепортировать NPC
/npc stats                        - Общая статистика
```

### Управление поведением
```
/npc config <имя> <параметр> <значение>  - Настройка NPC
/npc task <имя> <задача> [параметры]     - Назначить задачу
/npc team create <лидер>                 - Создать команду
/npc team join <член> <лидер>            - Присоединиться к команде
```

### Общение с NPC
```
/talk <имя> [сообщение]           - Поговорить с NPC
/npcsay <имя> <сообщение>         - Заставить NPC сказать что-то
/npcmood <имя> <настроение>       - Изменить настроение
/npcemotion <имя> <эмоция> <значение>  - Настроить эмоцию
```

### Чат-команды
Можно обращаться к NPC напрямую в чате:
```
Атлас, построй дом из дуба
Торговец, покажи свои товары  
Боб, следуй за мной
Стражник, охраняй это место
```

## 🔧 Установка и настройка

### Требования
- Minecraft 1.21
- Fabric Loader 0.15.11+
- Fabric API 0.100.6+
- Java 17+

### Установка
1. Скачайте мод из релизов
2. Поместите `.jar` файл в папку `mods`
3. Запустите Minecraft с Fabric

### Настройка LLM
Мод поддерживает несколько вариантов подключения к LLM:

#### OpenAI API
```bash
# Установите переменную окружения
export OPENAI_API_KEY="your-api-key-here"
```

#### Ollama (локально)
```bash
# Установите Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Запустите модель
ollama run llama3.1:8b
```

#### Пользовательская LLM
Настройте URL в веб-панели или через переменную `OLLAMA_URL`

## 📁 Структура памяти

Каждый NPC сохраняет свои данные в `intelligentnpc/memory/<имя_npc>.json`:

```json
{
  "npc_name": "Atlas",
  "known_players": {
    "Player1": {
      "relationship_level": 0.8,
      "interactions": ["Said hello", "Helped with building"]
    }
  },
  "experiences": [
    {"category": "building", "description": "Built a house", "timestamp": "..."}
  ],
  "skills": {
    "building": 15,
    "trading": 8,
    "combat": 12
  },
  "personality_traits": {
    "friendliness": 0.7,
    "humor": 0.5,
    "cautiousness": 0.6
  }
}
```

## ⚙️ Конфигурация

### Параметры NPC
```
role - роль NPC
chattiness - общительность (0.0-1.0)
aggression - агрессивность (0.0-1.0) 
building_range - радиус строительства
team_leader - может ли быть лидером команды
learning_rate - скорость обучения
```

### Настройки мода
- Максимальное количество NPC: 50
- Максимум NPC на игрока: 5
- Порты веб-сервисов: 8123 (HTTP), 8124 (WebSocket)
- Интервал LLM запросов: 3 секунды
- Автосохранение памяти: каждые 10 минут

## 🔌 WebSocket API

Для разработчиков доступен WebSocket API на порту 8124:

```javascript
const ws = new WebSocket('ws://localhost:8124/ws/llm');

// Получение списка NPC
ws.send(JSON.stringify({
  type: 'get_npcs'
}));

// Отправка команды NPC
ws.send(JSON.stringify({
  type: 'llm_request',
  request_id: 'unique_id',
  context: {
    npc_name: 'Atlas',
    command: 'build house'
  }
}));
```
